# Oteryn Atlas

`Oteryn-Atlas` is the derived semantic browser atlas for the Oteryn ecosystem.

## Authority boundary

- Oteryn-Game owns canonical World/Content semantics.
- Oteryn-Atlas consumes explicit, versioned, public-safe Game exports and owns derived indexing, browser rendering, search, inspection and publication.
- Legacy OTBM/Tibia/Canary/Crystal data is not a browser-runtime source of truth.
- Atlas must not become a second authoritative item/NPC/monster/loot database.

## Initial programme

The first bounded implementation task is `DYN-ATLAS-001 — Semantic Thais Z7 Proof`, governed by the canonical Platform architecture/programme and Game-owned export/spatial contracts.

No production deployment, full-map conversion, live-state bridge, editor writes or permanent serialization choice is implied by this bootstrap.
